# Multimodal Search and Context-Aware Recommender Engine

## Day 1 Setup

This repository contains the initial Python project setup for a multimodal recommender system.

### Files added

- `requirements.txt`: core dependencies for the Python stack.
- `data_loader.py`: script for loading and cleaning text/image metadata into a structured dataset.
